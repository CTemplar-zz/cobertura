# Cobertura & Piscicultura

Geoportal interactivo para explorar la evolución de la cobertura terrestre
asociada a estanques piscícolas en la Amazonía boliviana entre 2010 y 2025.

## Acceso público

https://ctemplar-zz.github.io/cobertura/

El sitio se publica automáticamente en GitHub Pages con cada actualización de
la rama `main`.
